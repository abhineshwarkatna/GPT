# Hyper Futuristic Orb Landing Page

An advanced React + Three.js / React Three Fiber cinematic landing page.

## Included
- Procedural hyper-futuristic mechanical orb with nested gyroscopic rings
- Refractive glass armor panels and emissive metallic core
- 1,400 optimized ambient particles plus Sparkles
- Mouse-driven camera parallax
- Scroll-driven orb deconstruction/exploded architecture
- Cobalt + amber cinematic lighting
- Bloom, chromatic aberration and vignette post-processing
- Frosted-glass HUD elements and responsive mobile layout
- Vite development/build setup

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
